Quiet night console

The visual catalog for a personal logger that runs at 2am with a thumb, and at a desk with a keyboard. Everything here is dark, low-noise, and instrument-like: light numerals, tabular figures, hairline rules, and one purple accent that only appears where something is actionable. Behavior and release requirements live in the UI/UX engineering manual.

01

Principles

Six rules that decide every visual argument in this app. When a component looks wrong, it is almost always breaking one of these.

Rule Fast when the data is certain

An instant event with safe defaults logs at now. A composed record opens its shortest trustworthy form. Detail is never fabricated to save a tap.

Rule Accent means actionable

--accent marks the current nav item, the primary button, the live "now" marker, and nothing else. Decorative purple dilutes the signal.

Rule Numbers are instruments

Readouts use weight 300 at large sizes with tabular-nums, so digits never shift as values tick. Labels stay 10px uppercase with wide tracking.

Rule Hairlines, not boxes

Separation comes from --line at 8% and a change of surface. Heavy borders and drop shadows are reserved for things that float.

Rule Two surfaces, one system

Below 1024px the app is a one-thumb logger; above it is a three-column console. Sheets, tones, and tokens are shared — only layout and density change.

Rule Every destructive act is reversible

Deletes use a soft archived_at stamp behind a 5s Undo. The target also requires a user-visible Restore path after that window; current production only has operator/database recovery.

Buttons

button is reset globally to inherit font and color with no border or background, so every button here is additive. Focus is always a 2px accent outline at 2px offset — never removed.

Primary actions

Log button

.logBtn

The commit action inside every sheet. Full width, 64px, radius 22, solid accent on --bg text. Disabled drops to 40% opacity.

Delete + footer

.deleteBtn · .editFooter

Destructive is outlined, never filled, and always narrower than the confirm action (1fr / 2fr grid).

Wide capture

.wideCap

Outlined accent, 48px. For actions that always open a sheet because they need input (meal name, gym exercises).

Chip

.chip — global.css

Pill, 44px, tabular. Pressed swaps to --surface-raised with a --sleep-dim border. Press scales to .95.

Text-level actions

Accent = constructive (edit, undo a delete). --t2 = neutral. --bad = the destructive one, and it only appears once per row.

Current legacy debt — do not copy the looping wheel

WheelTimePicker.tsx duplicates option values, cannot be typed into directly by default, conflicts with mobile sheet scrolling, and only exposes Today/Yesterday. Keep it visible in the conformance register until production migrates to the target field above.

Do Let people type

Date and time are visible inputs on desktop. React Aria enforces 24-hour segments; native fallback display follows the device locale. The picker is an additional path.

Do Offer any allowed date

Now, Today, and Yesterday are shortcuts. The explicit date field covers the complete permitted range.

Don't Dismiss from content

Swipe-to-dismiss begins only on the handle/header. Input, calendar, and form-body scrolling never move the sheet.

Don't Guess precision

Approximate values remain ranges or named periods through history and analysis; changing a value does not silently make it exact.

Gauges

Two custom SVG instruments, both in the CBT flow, both driven by a native input underneath so touch and keyboard keep working. They exist because a number field cannot convey how much at a glance.

SUDS dial

cbt/IntensityDial.tsx

A 78px-radius semicircle on a 200×112 viewBox, 10px stroke with round caps. The fill is a stroke-dasharray of (value / 100) × πr. Color ramps by band — below 34 --ok, below 67 --warn, otherwise --bad — and the numeral takes the same color. A range input at step 5 sits below the arc.

calmunbearable

Evidence balance

cbt/EvidenceScale.tsx

A beam on a 240×96 viewBox that physically tips toward the heavier pan: 3.5° per fact, clamped to ±11°, transitioning over --duration-normal. The left pan (evidence for the thought) is the bad pair; the right pan (against) is the ok pair. Watching "against" outweigh "for" is the entire point of the exercise.

Rules & traps

Conventions that are not obvious from reading a component, and the specific mistakes that have already cost time in this codebase.

Styling

Don't Hardcode a hex

Every color comes from styles/tokens.css. If a value is missing, add a token — don't inline it.

Do Keep hide queries last

The display:none breakpoints in nav.module.css and the nutrition console have equal specificity to the rules they override — source order is what makes them win.

Note Legacy aliases still live

Pre-redesign components read --sleep, --intake, --state, --bg, --ink, --dim. They alias the new names; both are valid.

Do Respect reduced motion

global.css collapses all animation and transition to 0.01ms under prefers-reduced-motion. Don't reintroduce motion through inline styles.

Behaviour

Do Soft-delete and restore

Deletes stamp archived_at; every normal read filters archived_at IS NULL. Provide immediate Undo and a user-visible archived-records Restore path. Never issue a hard DELETE.

Do Invalidate both caches

/api/today and /api/week are cached 60s. invalidateToday() clears the week slot too, by design — never add a write path that skips it.

Don't Edit a ghost row

Optimistic rows carry a ghost- id prefix and are never editable or deletable. They clear per-row when the real event lands.

Note Time is wall-clock

occurred_at is text holding the exact ISO string with its original offset; occurred_ts exists only for ordering. Any write must set both. Use lib/time.ts — never hand-roll date maths.

Traps that have already bitten

Trap useEffect on a rebuilt array

An effect depending on pages.flatMap(...) created an infinite render loop that silently starved all router navigation app-wide — taps did nothing, no errors. Hooks returning derived arrays must useMemo them.

Trap next/link for nav

Link-click transitions stall on Next 15.5 here. Use NavLink.tsx, and verify nav in real Chrome against localhost:3199 — not the preview harness.

Trap Stale is usually the cache

During manual testing, "wrong" data from /api/today or /api/week is almost always the 60s server cache, not a bug. Any write invalidates it.

Keeping this page honest

This page is a mirror, not a source. When a token changes, edit app/styles/tokens.css first and copy it into design-system/styles/tokens.css. When a component changes, update its CSS module first and mirror the block in design-system/styles/components.css — the header of that file maps every class back to the module it came from.
